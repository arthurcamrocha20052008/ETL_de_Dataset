# 📊 ETL e Análise de Dados — Rede de Oficinas

Projeto desenvolvido em Python para realizar o processo de **ETL (Extract, Transform, Load)** e análise exploratória de dados de uma rede de oficinas.

O projeto utiliza uma base de dados em Excel com registros de serviços realizados, permitindo realizar tratamento dos dados e gerar gráficos para identificar padrões e informações relevantes.

---

## 🚀 Sobre o Projeto

O objetivo deste projeto é aplicar conceitos de **Análise de Dados e ETL** utilizando Python.

Durante o projeto são realizadas etapas de:

- Importação de dados de uma planilha Excel;
- Exploração inicial do dataset;
- Limpeza e tratamento dos dados;
- Padronização de cidades;
- Tratamento de valores monetários;
- Conversão de tipos de dados;
- Tratamento de datas inválidas;
- Identificação e remoção de registros duplicados;
- Tratamento de valores negativos;
- Análise dos serviços realizados;
- Criação de gráficos para visualização dos dados.

---
